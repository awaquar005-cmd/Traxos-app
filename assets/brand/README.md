# Traxos mark

Transparent SVG and matching native Android VectorDrawable contain five separate rounded squares; no raster or background embedded. Provisional geometry rebuilt from V3's explicit brand description because the inline attachment is nearly black and no raster original is accessible in the filesystem. This is not a claimed pixel-exact trace. Replace geometry against a usable original before brand/release approval. UI tint uses theme foreground; canonical SVG ink is #111B2F.

Google identity button asset (0.13.0): `app/src/main/res/drawable/google_g.png` is the unmodified official PNG downloaded from https://developers.google.com/static/identity/images/g-logo.png on2026-11-13. It is separate from Traxos branding and used for Google sign-in. The existing five-square Traxos mark/watermark assets were not changed.
