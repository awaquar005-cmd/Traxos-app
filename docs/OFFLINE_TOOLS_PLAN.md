# 0.8 — complete offline ledger tools

Scope chosen from the existing V3 P0 ledger roadmap: Activity date/account/category/currency filtering, saved newest/oldest sorting, monthly category reports with drill-through, and deleted-transaction recovery. These reuse the real ledger; preview-only future modules stay isolated. No cloud, OCR, new permission/dependency, permanent deletion or artificial financial data.

Acceptance: Room-filtered/paged lists, inclusive date validation and draft-preserving filter sheet; archived references remain selectable; all reset controls work. Sorting persists independently in Settings and Activity through schema7→8 preference-only migration. Monthly reports separate currencies, income, purchases/refunds; omit tombstones, transfers and card settlements, retain archived history, update reactively and drill to precisely matching activity. Recently Deleted pages one row per linked movement, restores both legs atomically with revision/idempotency guards and Undo; old deleted entries stay recoverable without invented deletion timestamps or purge timers. Loading/empty/error/retry, balance masking, compact outlined controls, Back/close, large fonts and light/dark are required.

Validation: unit/integration tests for combined filters, literal search, month/year/leap boundaries, negative net refunds and mixed currencies, restore/repeated taps/stale revision/pair integrity/restart, preferences/migration; UI tests for filter sheet drafts/apply/reset, reports/drill-through, restore confirmation and Undo, navigation/settings persistence and narrow themes. Build both variants, full tests and lint; retain original signing key. Physical device/IME/TalkBack/OEM acceptance remains explicitly pending.

Follow-up feedback: keep borders minimal (half-dp) on action buttons only, exempt the logo, and fix Android12 splash mask clipping with a dedicated padded transparent mark. Add a native drawable mask/component test; physical OEM startup acceptance remains pending.
